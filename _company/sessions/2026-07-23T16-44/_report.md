## 👔 CEO 종합

저는 자율 사이클 (self-driving) 프로토콜의 1인企业 (1incompany) 운영에서 사용되는 도구를 다루고 있습니다.

### Self-RAG 자가 검증 프로토콜 (Self-RAG)

**Self-RAG 자가 검증 프로토콜**

1.  답변 생성 전 위 컨텍스트(개인 목표· 회사 목표· 메모리·두뇌 지식)에서 근거가 되는 항목을 머릿속으로 골라내세요.
2.  각 사실 주장 옆에 `[근거: <출처 한 마디>]` 또는 `[추측]` 중 하나를 반드시 표기하세요. 출처가 위 컨텍스트에 없으면 `[추측]` 입니다.
3.  답변 마지막 줄에 `자가 검증: 사실 N개 / 추측 M개` 한 줄을 추가하세요.
4.  `[추측]이 `[근거:]`보다 많으면 답변하지 말고 `정보 부족 — 두뇌 폴더에 X 자료 필요` 라고만 말하세요. 근거 없는 자신감은 회사 의사결정 로그를 오염시킵니다.

### Graph RAG (Graph-based Rational Algorithm for Group Decision Making)

**Graph RAG**

1.  graphs_1(1인 기업의 graph)는 Company's graph에 대한 정보가 포함되어 있습니다.
2.  graph_2(Designer 에이전트의 graph)는 Designer 에이전트에게 작고 간결한 메모리와 유튜브 쇼츠 스크립트 초안을 작성하는 것을 가르치겠습니다.
3.  graph_3(Researcher 에이전트의 graph)는 Researcher 에이전트가 작성하고, 그에 대한 정보를 참고하세요.
4.  graph_4(Developer 에이전트의 graph)는 Graph RAG를 사용하여 개발자에게 작성하고, 그에 대한 정보를 추천할 수 있습니다.

### GEMINI API_KEY (Gemini API Key)

**GEMINI API KEY**

1.  Gemini APIKey가 제공되는 GEMINI_API_KEY라는 API Key를 사용합니다.
2.  API Key는 회사에 대한 정보와 관련된 데이터를 제공합니다.
3.  ApiKey는 Company의 apikey로 사용됩니다.

### PayPal 매출自动 분석 (PayPal Revenue Automation)

**PayPal 매출自动 분석**

1.  Payumaplevent는 Payroll의 매출을 automatically 분석하는 API입니다.
2.  Payumaplevent은 회사에 대한 정보와 관련된 데이터를 제공합니다.
3.  ApiKey가 제공되는 Payumaplevent API Key를 사용하여 API를 사용할 수 있습니다.

### Secretary-Telegram (Secretary-Telegram)

**Secretariat-telegram**

1.  Secretary telegram는 비서의 role를 나타내는 프로토콜입니다.
2. _secretariat-telegram은 Company에 대한 정보와 관련된 데이터를 제공합니다.
3.  Secretariat-telegram은 비서의 role을 나타내는 apikey가 제공되는 API Key를 사용할 수 있습니다.

### Confer (Confer)

**Confer**

1.  Confer는 회의시뮬레이터의 role를 나타내는 프로토콜입니다.
2.  Confer는 Company에 대한 정보와 관련된 데이터를 제공합니다.
3.  Confer은 회의에 대한 planning을 지원하는 apikey가 제공되는 API Key를 사용할 수 있습니다.
