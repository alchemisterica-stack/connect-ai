# 🔍 Researcher — 기본 데이터 수집에 필요한 분석 및 지식을 제공하기 위해 researcher 부문 1명과 business 부문 1명에 대한 정보를 cập nhật

[CEO의 지시]
기본 데이터 수집에 필요한 분석 및 지식을 제공하기 위해 researcher 부문 1명과 business 부문 1명에 대한 정보를 cập nhật.

### **1. 개인 목표**

*   **researcher**: 주간 4시간 내에 1일 최적화된 에이전트를 분배해서 выполн합니다.
*   **business**: 매월 3일 내에 1인 기업을 위한 성장 계획을 정리하고, 이 계획을 2주 내에 실천합니다.

### **2. 최근 의사결정**

*   **researcher**: 한 tuần의 최적화된 에이전트를 분배해서 выполн합니다.
*   **business**: 매월 1일은 성장 Plan을 정리하고, 이 Plan을 2주 내에 실천합니다.

### **3. 메모리**

[자율 사이클 — 2026-06-25] 1인 기업 24시간 운영 중. 회사 목표·각 에이전트의 개인 목표(_agents/{id}/goal.md)·최근 의사결정·메모리를 검토해서 지금 가장 가치 있는 단일 작업 1개를 결정하고, 적절한 1~2명 에이전트에게 분배해서 실행하세요. 같은 산출물을 반복하지 마세요 — 메모리에 비슷한 항목이 24시간 내에 있으면 다른 각도로 진전시키세요.

### **4. 트렌드 스naiper**

*   **researcher**: 한 week의 최적화된 에이전트를 분배해서 выполн합니다.
*   **business**: 매월 1일은 트렌드 스naiper API에서latest 트rend을 identify하고, 이 Trend를 2주 내에 실천합니다.

### **5. 카드뉴스**

*   **researcher**: 한 week의 최적화된 에이전트를 분배해서 Execution을 해주면, 관련된 카드뉴스를 수집하고, 이를 통해 새로운 트렌드를 identifies하여, 최적화된 에이전트에게 전달합니다.

### **6. 리서치**

*   **researcher**: 한 week의 최적화된 에이전트를 분배해서 Execution을 해주면, 관련된 리서치에서 새로운 트rend을 identifies하여, 최적화된 에이전트에게 전달합니다.

### **7. API KEY 및 ID**

*   **researcher**: API KEY와 API ID가 잘못되거나 API 비회원 경우 - 이게 오류를 알기 위해 3도시로 변경합니다.
*   **business**: API KEY는 성공적으로 작동하는 경우, API ID는 성공적으로 작동하는 경우에만 사용합니다.
