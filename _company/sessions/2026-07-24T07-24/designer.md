# 콩콩캔디 '완도 전복죽' 인스타그램 카드뉴스 디자인 브리프

## 1. 프로젝트 개요
'완도 전복죽' 콘텐츠를 인스타그램 카드뉴스 형태로 제작하며, 브랜드 가이드라인을 준수하여 비주얼 에셋의 자동 생성을 목표로 합니다. CEO의 '썸네일 장악' 목표에 부합하도록 시각적 일관성과 주목도를 높이는 데 중점을 둡니다.

## 2. 브랜드 아이덴티티

### 2.1. 로고
-   **로고 파일:** 콩콩캔디 로고 (투명 배경 PNG 또는 SVG)
-   **배치:** 모든 카드 페이지의 상단 중앙
-   **여백:** 상단에서 20px, 좌우 여백 20px 이내
-   **크기:** 가로 80px (세로 비율 유지)

### 2.2. 컬러 팔레트
-   **Accent Yellow:** `#FFD700` (RGB: 255, 215, 0)
    -   적용 대상: 제목, 핵심 키워드
-   **Primary Blue 계열:** `#4A67A3` (RGB: 74, 103, 163)
    -   적용 대상: 테두리, 그림자 효과
-   **기본 텍스트 색상:** `#333333` (RGB: 51, 51, 51)
    -   적용 대상: 본문 텍스트 (가독성 확보)
-   **배경색:** `#FFFFFF` (RGB: 255, 255, 255) 또는 미색 `#F8F8F8` (깔끔하고 밝은 느낌)
    -   적용 대상: 기본 카드 배경

### 2.3. 타이포그래피
-   **메인 폰트:** Noto Sans KR
-   **폰트 스타일 및 적용:**
    -   **제목 (페이지 타이틀):** Noto Sans KR Bold, 28pt, Accent Yellow (`#FFD700`), 중앙 정렬
    -   **핵심 키워드/부제목:** Noto Sans KR Bold, 20pt, Accent Yellow (`#FFD700`), 중앙 정렬
    -   **페이지 소제목:** Noto Sans KR Bold, 24pt, Accent Yellow (`#FFD700`), 좌측 또는 중앙 정렬 (콘텐츠에 따라 유동적)
    -   **본문 텍스트:** Noto Sans KR Regular (또는 Medium), 16pt, 기본 텍스트 색상 (`#333333`), 좌측 정렬 (줄 간격 1.5em 권장)

## 3. 카드뉴스 구성 원칙

### 3.1. 레이아웃 (각 카드 페이지)

#### 3.1.1. 1페이지 (메인 타이틀 페이지)
-   **상단:** 콩콩캔디 로고
-   **중앙 상단:** 메인 제목 (예: "완도 전복죽", Accent Yellow, Noto Sans KR Bold, 28pt)
-   **중앙 하단:** 핵심 키워드/부제목 (예: "바다의 보물, 집에서 즐기는 명품 한 그릇", Accent Yellow, Noto Sans KR Bold, 20pt)
-   **배경:** 완도 전복죽 또는 신선한 전복 관련 고품질 이미지 (텍스트 가독성을 위해 30~50% 투명도 오버레이 또는 블러 효과 적용)
-   **전체 테두리/그림자:** Primary Blue 계열 테두리 및 그림자 효과 적용

#### 3.1.2. 2페이지 이후 (콘텐츠 페이지)
-   **상단:** 콩콩캔디 로고
-   **상단 중앙:** 각 페이지별 소제목 (Accent Yellow, Noto Sans KR Bold, 24pt)
-   **중앙:** 본문 텍스트 (기본 텍스트 색상, Noto Sans KR Regular, 16pt, 좌측 정렬)
-   **하단:** 내용 보조 이미지 또는 아이콘 (텍스트 내용과 연관성 높은 이미지 사용)
-   **테두리/그림자:** Primary Blue 계열 테두리 및 그림자 효과 적용

### 3.2. 이미지 사용 원칙
-   **품질:** 고해상도, 저작권 문제 없는 이미지 사용
-   **주제 연관성:** 완도 전복, 전복죽, 바다, 건강, 요리 과정 등 콘텐츠 주제와 명확히 연관된 이미지 선택
-   **배경 이미지 처리:** 텍스트 가독성을 최우선으로 고려하여, 배경 이미지는 블러, 명도/채도 조절, 컬러 오버레이 등으로 텍스트를 방해하지 않도록 처리
-   **아이콘:** 사용 시, 일관된 스타일 (예: 플랫 디자인, 라인 아이콘) 유지

### 3.3. 테두리 및 그림자 효과
-   **테두리:** 2px 두께, Solid, Primary Blue 계열 (`#4A67A3`)
-   **그림자 효과:**
    -   색상: Primary Blue 계열 (`#4A67A3`, 투명도 30% ~ 50% 적용, 예: `rgba(74, 103, 163, 0.3)`)
    -   오프셋: X축 4px, Y축 4px
    -   블러: 8px
    -   스프레드: 0px (필요 시 조절 가능)
    -   적용 대상: 모든 카드 페이지의 전체 프레임

## 4. 자동 생성 스크립트 고려 사항
-   모든 디자인 요소(색상 코드, 폰트명, 폰트 크기, 여백, 좌표, 이미지 경로, 텍스트 내용 등)는 스크립트 내에서 변수화하여 쉽게 변경 및 자동화 가능하도록 구조화합니다.
-   각 페이지의 레이아웃은 그리드 시스템 또는 고정된 좌표 기반으로 명확하게 정의하여 스크립트가 정확하게 요소를 배치할 수 있도록 합니다.
-   테두리 및 그림자 효과는 CSS 속성 또는 이미지 처리 라이브러리의 파라미터로 직접 적용 가능하도록 명시합니다.

## 5. 레퍼런스 이미지 컨셉
텍스트 기반 브리프이므로 실제 이미지를 첨부하는 대신, 영감을 얻을 수 있는 시각적 컨셉을 설명합니다.

1.  **푸드 스타일링:** 정갈하고 먹음직스러운 전복죽을 클로즈업한 사진. 배경은 최소화하고 음식 자체의 질감과 색감에 집중하여 고급스러움을 강조합니다.
2.  **한국적 미니멀리즘:** 여백을 충분히 활용하고, 은은한 한국 전통 문양이나 자연적인 질감(나무, 한지 등)을 배경에 미미하게 넣어 동양적인 고급스러움을 표현합니다.
3.  **컬러 포인트 강조:** 전체적으로 깔끔하고 밝은 배경에, 제목과 핵심 키워드에만 Accent Yellow를 강렬하게 사용하여 시선을 집중시키고 정보의 중요도를 부각합니다.
4.  **인포그래픽 요소:** 전복의 효능, 요리 과정 등을 간결한 아이콘과 짧은 문구로 구성하여 정보 전달력을 높이고, 시각적 지루함을 해소합니다.
5.  **통일된 브랜드 룩:** Primary Blue와 Accent Yellow 컬러 팔레트를 일관되게 적용하여 콩콩캔디 브랜드 아이덴티티를 명확히 드러내는 인스타그램 피드 예시 (전체적인 톤앤매너 참고용).

이 브리프는 '완도 전복죽' 인스타그램 카드뉴스 비주얼 에셋 자동 생성을 위한 기준점이 됩니다.
