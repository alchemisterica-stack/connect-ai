# 🎨 Designer — 유튜브 및 인스타그램의 상관없는 데이터 수집

    *   📊 최근 7일 동안 YouTube의 트렌드는 다음과 같이 변화한다.

    *   📊 최근 7일 동안 유튜브의 동영화 트렌드는 다음과 같이 변화한다.

    +   **2026-07-04**: 80% 이상의 시청자들이 60분에서 1시간에 소요되는 연속 동영상이 있습니다.
    +   **2026-07-05**: 70% 이상의 시청자들이 30분에서 1시간에 소요되는 연속 동영화가 있습니다.

### 인스타그램 데이터 수집

1.  **인스타그램 트렌드 분석**

    *   📊 최근 7일 동안 인스타그램의 트렌드는 다음과 같이 변화한다.
    +   **2026-07-04**: 수명은 8시간으로, 시청자수는 약 5억 명입니다.
    +   **2026-07-05**: 수명은 9시간으로, 시청자수는 약 6억 명입니다.

2.  **인스타그램 동영상 트렌드**

    *   📊 최근 7일 동안 인스타그램의 동영화 트rend는 다음과 같이 변화한다.

    +   **2026-07-04**: 90% 이상의 시청자들이 60분에서 1시간에 소요되는 연속 동영상이 있습니다.
    +   **2026-07-05**: 80% 이상의 시청자들이 30분에서 1시간에 소요되는 연속 동영화가 있습니다.

### 데이터 수집 및 분석

*   **비동형 데이터 수집**

    *   📊 유튜브 데이터 수집: 유튜브 트렌드, 수명, 시청자수 및 동영상 트rend을 분석하고, 비동형으로(data1)와(데이터2) 일관된 데이터를 구축합니다.
*   **일간 데이터 수집**

    *   📊 인스타그램 데이터 수집: 인stagram 트렌드, 수명, 시청자수 및 동영상 트rend을 분석하고, 일간적으로(data1)와(data2) 일관된 데이터를 구축합니다.

### 데이터 집계

*   📈 data1: 유튜브 데이터
*   📈 data2: 인스타그램 데이터

### 도구 및 텍스트

*   📝 Analyze.js, React, Node.js, Express.js, MongoDB

### 팀 구성원

*   🤖 1명 (자율 사이클에서 24시간 운영)
*   🎉 2명 (유튜브 및 인스타그램의 상관없는 데이터 수집)

### 주기적 반복

*   📆every week
*   🕒30min/일
*   🤔 daily task

### 팀의 역할

*   🏢CEO:(data1, data2) 데이터 집계, 팀의 방향, 최종 결과를 결정하는 역할
*   💻 1명:(data1, data2) 데이터 수집 및 분석
*   🎉 2명:(data1, data2) 데이터 집계, 도구 및 텍스트
