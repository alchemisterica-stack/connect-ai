# 여름 식탁의 보석, 감칠맛 폭발하는 실패 없는 호박볶음 레시피


창밖으로 내리쬐는 뜨거운 햇살을 보니 어느덧 완연한 여름이 왔나 봐요.


장바구니에 담긴 파릇파릇하고 묵직한 애호박 하나를 보니, 돌아가신 할머니가 여름마다 뚝딱 만들어주시던 그 달큰한 호박볶음 생각이 간절해지더라고요.


오늘은 저만의 비법으로, 물러지지 않고 식감은 살리면서 감칠맛은 극대화한 특별한 호박볶음을 소개할게요.



## 정성 가득 담긴 준비물


먼저 싱싱한 재료를 준비하는 것부터가 요리의 시작이죠.


깔끔하게 정리한 재료 리스트를 확인해 보세요.



| 재료 | 분량 |
| :--- | :--- |
| 애호박 | 1개 |
| 양파 | 1/2개 |
| 다진 마늘 | 1큰술 |
| 새우젓(또는 새우가루) | 1큰술 |
| 들기름 | 2큰술 |
| 소금 | 약간 |



## 실패 없는 호박볶음, 첫 번째 비법



가장 먼저 애호박을 썰어줄 건데요, 너무 얇으면 볶을 때 형태가 뭉개지기 쉬워요.


0.5cm 정도의 두께로 도톰하게 썰어주시는 게 핵심이에요.



> **TIP: 애호박에 소금을 살짝 뿌려 10분 정도 절인 뒤 물기를 꽉 짜주세요!**
> 이렇게 하면 볶는 도중 수분이 많이 나오지 않아 훨씬 꼬들꼬들한 식감을 즐길 수 있답니다.



## 향긋하게 볶아내는 과정



이제 프라이팬에 들기름을 두르고 다진 마늘을 먼저 넣어보세요.


지글지글 마늘 향이 집안 가득 퍼지기 시작하면 벌써 맛있는 냄새에 배가 고파지죠.



이때 절여둔 호박과 채 썬 양파를 넣고 중불에서 달달 볶아주세요.


호박의 단면이 투명해지기 시작하면 바로 지금이 간을 할 타이밍이에요.



## 감칠맛의 정점, 새우가루



호박볶음의 풍미를 결정짓는 건 바로 '새우'예요.


저는 개인적으로 새우젓도 좋지만, 마른 새우를 곱게 갈아 만든 **새우가루**를 사용하는 걸 강력하게 추천해요.



> **새우가루를 한 스푼 넣으면 호박의 달큰한 맛과 만나 깊은 바다의 풍미가 배어 나옵니다.**
> 따로 육수를 낼 필요 없이 감칠맛이 폭발하는 비결이 바로 여기에 있죠.



## 마지막까지 정성스럽게



너무 오래 볶으면 호박이 죽처럼 변할 수 있으니 주의해야 해요.


채소의 아삭함이 살짝 남아있을 때 불을 끄고 남은 잔열로 마무리해 보세요.



접시에 담아내고 깨를 솔솔 뿌려주면, 여름 햇살을 닮은 노란 빛깔의 호박볶음이 완성됩니다.


따끈한 흰 쌀밥 위에 듬뿍 올려 먹으면 다른 반찬이 전혀 부럽지 않아요.



오늘 저녁, 소박하지만 정성이 담긴 이 호박볶음으로 가족들에게 건강한 여름 밥상을 선물해 보시는 건 어떨까요?


여러분의 식탁에도 시원하고 행복한 웃음이 가득하기를 바랄게요.

# 여름철 입맛을 깨우는 아삭한 호박볶음, 실패 없는 황금 레시피


무더운 여름, 식탁 위에 빠지지 않는 제철 채소가 바로 애호박입니다.


오늘은 물러지기 쉬운 애호박을 형태 그대로 살리면서, 감칠맛은 극대화한 '호박볶음' 비법을 소개합니다.


누구나 따라 할 수 있는 간단한 과정이지만, 몇 가지 포인트만 지키면 고급 한정식집 부럽지 않은 맛을 낼 수 있습니다.



## 1. 재료 준비하기


먼저 정량에 맞춰 재료를 준비해 주세요. 재료가 신선할수록 식감이 좋아집니다.


| 재료 | 분량 |
| :--- | :--- |
| 애호박 | 1개 |
| 양파 | 1/2개 |
| 홍고추 | 1/2개 |
| 다진 마늘 | 0.5큰술 |
| 새우젓 | 1큰술 |
| 들기름 | 2큰술 |
| 식용유 | 1큰술 |
| 깨 | 약간 |



## 2. 식감 살리는 밑작업


호박볶음을 할 때 가장 흔한 실수는 애호박이 뭉개지며 물이 생기는 것입니다.


이를 방지하기 위해 반드시 **'소금 절이기'** 과정을 거쳐야 합니다.



### 소금에 절여 단단하게 만들기


애호박을 0.5cm 두께로 반달 썰기 합니다.


볼에 썬 호박을 담고 소금 1/3큰술을 뿌려 10분 정도 절여주세요.


> **Tip:** 소금에 절인 뒤 나오는 물기는 키친타월로 가볍게 닦아내면 볶을 때 형태가 부서지지 않습니다.



## 3. 맛을 내는 조리 단계


이제 본격적으로 볶아볼 시간입니다. 중불에서 빠르게 볶아내는 것이 핵심입니다.



### 향신 채소로 맛 내기


팬에 식용유 1큰술과 들기름 2큰술을 두릅니다.


다진 마늘을 먼저 볶아 향을 충분히 올려주세요.



### 호박과 양파 넣고 볶기


절여둔 호박과 채 썬 양파를 넣고 중강불에서 볶습니다.


양파가 투명해지기 시작하면 새우젓 1큰술을 넣어 간을 맞춥니다.


> **핵심 비법:** 새우젓은 호박과 최고의 궁합을 자랑하며, 천연 조미료 역할을 하여 깊은 감칠맛을 더해줍니다.



### 홍고추로 색감 더하기


마지막으로 홍고추를 넣고 30초 정도만 가볍게 볶아 마무리합니다.


너무 오래 볶으면 호박이 물러지니 주의하세요.



## 4. 맛있는 호박볶음을 위한 꿀팁


완성된 호박볶음은 접시에 옮겨 담고 깨를 살짝 뿌려 마무리합니다.


더욱 맛있는 결과를 위해 다음 세 가지를 기억하세요.



> **첫째, 들기름과 식용유를 혼합해서 사용하세요.** 들기름의 고소함과 식용유의 발연점이 만나 호박의 풍미를 살려줍니다.


> **둘째, 새우젓은 국물보다 건더기를 위주로 사용하세요.** 그래야 요리가 지저분해지지 않고 깔끔한 비주얼이 유지됩니다.


> **셋째, 잔열을 활용하세요.** 불을 끄고 마지막에 홍고추를 넣은 뒤 잔열로 익혀야 색감이 선명하게 유지됩니다.



오늘 저녁, 제철 애호박으로 시원하고 상큼한 밥상을 완성해 보시길 바랍니다.


간단한 재료로 만드는 정성 가득한 반찬이 가장 큰 보약입니다.
