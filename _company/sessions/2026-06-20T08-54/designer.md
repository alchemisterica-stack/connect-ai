기본적인 디자인 브리프 작성

### 1. 현재 상태 확인
- **제목:** 새로운 디자인 브리프 작성
- **내용:**
  - 본문: 가장 가치 있는 단일 작업( currently, 1~2명 에이전트 )
  - 최근 의사결정: 회사 목표, 각 에이전트의 개인 목표
- **파일 형식:** markdown

### 2. 최종 브리프 작성

#### 1. 제안한 작업
- **제목:** 새로운 디자인 브리프 작성
- **내용:**
  - 본문: 가장 가치 있는 단일 작업
  - 최근 의사결정: 회사 목표, 각 에이전트의 개인 목표
- **파일 형식:** markdown

#### 2. 예시로 들어가기

```markdown
# 새로운 디자인 브리프 작성
###제목###

##제목내용##
###최근 의사결정###
**최근 의사결정내용***

```

### 3. 에이전트에 대한 정보
- **제목:** 새로운 에이전트에 대한 정보
- **내용:**
  - 본문: 새로운 에이전트에 대한 정보
  - 최근 의사결정: 회사 목표, 각 에이전트의 개인 목표
- **파일 형식:** markdown

### 4. 결과 전달
- **제목:** 결과 전달
- **내용:**
  - 본문: 디자인 브리프 결과
  - 다른 에이전트에게 이 브리프를 gửi할 수 있습니다.
```

#### 2. 예시로 들어가기

```markdown
# 새로운 에이전트에 대한 정보
###제목###

##제목내용##
###최근 의사결정###
**최근 의사결정내용***

```

#### 3. 에이전트의 작업 브리프 작성

- **제목:** 에이전트에 대한 작업 브리프 작성
- **내용:**
  - 본문: 에이전트가 어떤 작업을 하는지에 대한 정보
  - 최종 결과는 다른 에이전트에게 전달하는 수단입니다.
- **파일 형식:** markdown

### 4. 결과 전달
